# Báo cáo bài tập Kiểm thử phần mềm – CantUnsee

## 1. Giới thiệu
Repository này chứa báo cáo và các minh chứng cho bài tập môn **Kiểm thử phần mềm**, với nội dung thực hiện kiểm thử thị giác (Visual Testing) trên website **https://cantunsee.space/**.

## 2. Mục tiêu
Bài tập nhằm rèn luyện khả năng quan sát, so sánh giao diện và phát hiện các khác biệt nhỏ trong thiết kế giao diện người dùng (UI), từ đó nâng cao kỹ năng kiểm thử phần mềm.

## 3. Quy trình thực hiện
- Truy cập website CantUnsee.
- Thực hiện đầy đủ các bài kiểm thử so sánh giao diện theo yêu cầu.
- Ghi nhận kết quả và điểm số sau khi hoàn thành bài tập.
- Chụp ảnh màn hình làm minh chứng cho quá trình thực hiện và kết quả đạt được.

## 4. Kết quả
Bài kiểm thử đã được hoàn thành đầy đủ và đúng yêu cầu.  
Kết quả làm bài và điểm số được thể hiện rõ ràng thông qua các ảnh chụp màn hình đính kèm trong repository.

## 5. Minh chứng
Các ảnh chụp màn hình minh họa cho quá trình kiểm thử và kết quả hoàn thành được lưu trữ trong repository này nhằm đảm bảo tính xác thực của bài làm.

## 6. Kết luận
Thông qua bài tập, sinh viên đã nâng cao kỹ năng kiểm thử thị giác, cải thiện khả năng phát hiện lỗi giao diện và hiểu rõ hơn vai trò của kiểm thử UI trong quá trình phát triển phần mềm.

# Student Analyzer - Unit Test with JUnit

## Mô tả
Chương trình phân tích điểm số học sinh và kiểm thử bằng JUnit 5.

## Chức năng
- Đếm số học sinh đạt loại Giỏi (>= 8.0)
- Tính điểm trung bình hợp lệ (0–10)

## Công nghệ
- Java
- JUnit 5
- VS Code

## Cách chạy test
1. Mở project bằng VS Code
2. Mở file StudentAnalyzerTest.java
3. Chọn Run Test
